# Carfax Abbey Demo

> Listen to them, the children of the night.
> What music they make!

## Installation

1. Open the **Extensions** view in VS Code or Cursor
2. Search for `carfax-abbey` and click _Install_
3. Pick **Carfax Abbey Wine** or **Carfax Abbey Crypt Black** under *Preferences: Color Theme*

See the [Open VSX listing](https://open-vsx.org/extension/rgsx/carfax-abbey) or the [README][readme].
